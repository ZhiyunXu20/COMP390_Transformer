small_try 做什么
----------------
在不动 base_1 全规模配置的前提下，用「子语料 + 小模型 + 固定步数」快速得到
可写进报告的对比结论（验证 loss / BLEU）。

推荐流程
--------
1) 全流程（大 batch + W&B + 日志，推荐）:
   mkdir -p logs && nohup bash run_fast_full.sh > logs/nohup_$(date +%Y%m%d_%H%M%S).log 2>&1 & echo $! > logs/nohup.pid
2) 或: bash run_compare.sh
   或分步：python create_subset.py → 两次 python train.py → python compare_runs.py

2) 阅读 report.txt；需要时把 metrics.json 里的数字贴进论文/实验报告。

3) 全规模复现请仍用 base_1（更长训练、更大模型）。

可调参数（不改 base_1）
------------------------
- create_subset.py --lines：子语料条数（越大越慢、越接近全分布）
- train.py --max-steps：训练步数
- config.py：d_model / n_layers / batch_size 等（small_try 专用）
- W&B 注意力图：config 中 wandb_log_attention / wandb_attention_every / attention_viz_decoder_layer；可用 --no-attention-plots 关闭

注意
----
- 子集上的相对结论（哪种注意力更好）通常可写；绝对 BLEU 与工业长训不可比。
- 两次训练已固定同一 config.seed，仅 attention_type 不同，便于公平对比。
